Privacy Policy

Voltage Divider Calculator

Effective Date: September 20, 2026

1. Introduction

This Privacy Policy explains how the Voltage Divider Calculator Android application handles information and user privacy.

The application is developed by Purendra Kumar Shakya.

2. Information Collection

Voltage Divider Calculator is an offline calculator application. The application does not require users to create an account or provide personal information to use its main calculation features.

The application itself does not collect, store, or transmit personal information to a developer-controlled server.

3. Calculator Data

Voltage, resistance, and other values entered into the calculator are processed locally on the user's device.

Calculation results are not uploaded to or stored on an external server by the application.

4. Clipboard

The application provides a Copy Result feature. When the user chooses to copy a calculation result, the result is copied to the device clipboard using the Android clipboard functionality.

The application does not use the copied result for advertising, analytics, or other data collection purposes.

5. Advertising and Analytics

The current version of Voltage Divider Calculator does not use third-party advertising SDKs such as Google AdMob.

The application also does not currently use analytics services, tracking SDKs, or a developer-controlled backend/database.

6. YouTube Link

The application contains a link that can open the developer's YouTube channel.

When a user opens YouTube, the user's interaction with YouTube is governed by YouTube's own terms and privacy policies. The application does not control the information collected by YouTube.

7. UPI Payment

The application provides an optional ₹99 support payment button that can open an installed UPI/payment application on the user's device.

The Voltage Divider Calculator application does not collect, store, or process the user's UPI PIN, bank account credentials, card information, or payment authentication information.

Any payment transaction is handled by the external UPI/payment application and its associated payment service provider.

8. Children's Privacy

Voltage Divider Calculator is a general-purpose electronics calculation application and is not specifically directed at children.

The application does not knowingly collect personal information from children.

9. Third-Party Services

The application may provide links to external services such as YouTube or UPI/payment applications. These services operate independently and may have their own privacy policies and data-handling practices.

Users should review the privacy policies of those external services when using them.

10. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes to the application or its features.

Any updated version will be published at this Privacy Policy URL.
